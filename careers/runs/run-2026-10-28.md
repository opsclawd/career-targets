## Method

1. Read `careers/careers_registry.csv` (446 data rows) and `careers/jobs_registry.csv` (1052 data rows) before updating; pulled with `git fetch origin main` + `git pull --ff-only origin main` first (the plain `origin/main` refspec was missing on the remote, so the fetch was issued explicitly).
2. Crawled the full Built In Calgary job board (standard + remote-only boards) and pulled each posting's JSON-LD `JobPosting` block for title, company, posted date, `jobLocation` and employer link.
3. Probed ATS boards directly (Ashby, Greenhouse, Lever, SmartRecruiters, Workable, Dover) for every company name already in the registry — 198 board hits, 8,641 posting records — plus every newly discovered company name.
4. Title filter: senior/staff/principal/lead/distinguished/intermediate + software/backend/full stack/platform/SRE/DevOps/data/AI-ML engineering. Rejected management, director, analyst, product, design, mobile-only, test/QA-only, devrel, sales/support, legal and intern/junior/student roles.
5. Location bucketing: Calgary/Airdrie/Cochrane -> `Calgary AB`; Alberta/Edmonton -> `Alberta AB`; standalone `CAN`/`Canada` and explicit Canada-remote -> `Remote Canada` (or `Canada` for non-hybrid Canadian postings). US-only, Europe-only, and non-Canada remote roles excluded.
6. Deduped by exact job URL first, then normalized company+title+location, then by a level-insensitive title core (senior/staff/principal/lead/II stripped) so re-listed roles found on a second board (AppDirect Senior vs Intermediate, Capco Senior vs plain SWE, Brex Senior vs SWE II backend, ClickUp Senior vs Staff Frontend, Ashby Senior vs Staff Product Engineer) counted once.
7. Questrade Dayforce board required an out-of-band approach: the public posting-search API and RSS endpoints return HTTP 403 to scripted requests, so job pages were enumerated directly by id (`/en-US/qfg/CANDIDATEPORTAL/jobs/<id>`) and parsed from `__NEXT_DATA__` for title, `postingStartTimestampUTC` and `postingLocations` (Calgary AB confirmed for 18202 / 18205 / 18213).
8. Verified every new job URL and every new careers URL returns HTTP 200/202 before writing.
9. Historical rows preserved: no deletions in either registry.
