## Method

1. Read `careers/careers_registry.csv` (303 rows) and `careers/jobs_registry.csv` (677 rows).
2. Ran four discovery sweeps:
   - `/tmp/newco_sweep.json` — new-company ATS boards (Ashby/Greenhouse/Lever/SmartRecruiters/Jobvite/Workday)
   - `/tmp/global_sweep.json` — global Canada-remote boards
   - `/tmp/cal_cos_sweep.json` — Calgary + Canada-remote boards
   - `/tmp/builtin_ats_sweep.json` — ATS detection across 115 Built In Calgary company boards
3. Built In Calgary job crawl (`/tmp/builtin_new.json`) produced new-company candidates; each candidate's board URL was probed (`/tmp/board_status.json`) and a direct employer careers page was validated where one existed (`/tmp/direct_probe.json`, `/tmp/probe2.py`).
4. Filtered on title (senior/staff/principal/lead/iii/ii/expert/head + engineering discipline), rejected QA/test-only, mobile, embedded, management, product, sales, support, analyst, consulting, intern/junior, and crypto/Web3 roles.
5. Location bucketing: Calgary -> `Calgary AB`, Alberta -> `Alberta AB`, Canada / Remote Canada -> `Remote Canada`. Explicit non-Calgary Canadian offices (Toronto/Vancouver/Montreal/Ottawa, etc.) excluded unless remote.
6. Deduped by exact job URL, then normalized company + title + location bucket. No overlap with existing registry rows (0 URL collisions, 0 key collisions).
